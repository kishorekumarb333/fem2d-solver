# fem2d-solver

A 2D nonlinear finite element solver built from scratch in C++17.

I'm a mechanical engineer building this to understand how a solver really works, step by step, and sharing the learning on LinkedIn.

## Tools
- C++17, CMake, Eigen, GoogleTest
- Ubuntu on WSL2, VS Code, Git

## Roadmap
1. Linear core: springs, then bar elements
2. Newton-Raphson
3. J2 plasticity
4. Large deformation
5. Arc-length

## Status
Toolchain set up. First test solves K·u = f for a two-spring chain.
